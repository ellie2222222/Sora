## Method

- A scratchpad script (`i18n-audit.mjs`) imports `en.ts` and `vi.ts` and flattens them to 454 dotted keys.
- It searches all source outside `locales/` for each key in `'…'`, `"…"` or `` `…` ``. The four dynamic template prefixes (`common.periods.`, `settings.themeNames.`, `settings.languageNames.`, `roles.`) count as readers.
- It lists literal `t('a.b'…)` keys missing from en, compares the en/vi key sets and identical values, and compares inline `defaultValue`/second-argument fallbacks against en.
- Hardcoded-text sweep: string-literal `placeholder`/`title`/`label`/`accessibilityLabel`/`message` props, JSX text nodes, and `Alert.alert`/`showToast`/`new Error` with literal text.
- Plural resolution checked with `i18next.createInstance()` using the app's own options (`compatibilityJSON: 'v4'`).

## Findings

1. **Broken plurals (bug, fixed).**
   - `compatibilityJSON: 'v4'` reads `_one`/`_other`, but the catalog used the legacy `_plural` suffix, so the plural form never rendered.
   - Reproduced: the old shape rendered `t('wallets.memberCount', { count: 3 })` → `"3 member"`.
   - Affected `accounts.viewTransactions`, `categories.usedByTransactions` and `wallets.memberCount`. They're now `_one`/`_other` in en and vi.
2. **Orphaned keys (74 removed).** 73 had zero readers in either quote style, including template prefixes. `home.crossWallet` lost its only reader in fix 4.
   - Examples: `common.delete/edit/rename/done/retry/yes/no/ok`, all `errors.sync*`, `valuation.*`, `settings.*Desc`, `home.greeting/totalBalance/…`, `wallets.roleAdmin/roleMember`.
   - Removed from en and vi by exact section path, and from the inactive locales with the typecheck loop (TS2353 and TS2561 excess-property errors). Inactive files show deletions only: 0 added / 62–63 removed each.
   - Kept, because this pass gives them readers again: `common.confirm` (keypad) and `settings.darkMode` (theme switch).
3. **Missing keys (15 added, en + vi).**
   - These were read with an English fallback, so Vietnamese users saw English:
     - not-found messages (account/budget/goal/wallet/invitation);
     - `wallets.selectWalletFirst`, `categories.noWalletSelected`, `goals.validAmountError`;
     - `settings.darkModeDesc/lightModeDesc/preview`;
     - four `transactions.*Label` keys and `transactions.detailTitle`.
   - Title Case fallbacks were normalised to the catalog's sentence case.
   - The vi text is my own translation of short UI strings. It's listed under Follow-ups for a native-speaker check.
4. **Fallback drift (11 fixed).** A key that exists shows its en value, never the fallback, so drift means the author expected different text.
   - **9 aligned** to the catalog. For example, `auth.signInLink` "Log in" → "Sign in", and `transactions.fromLabel` "From Account" → "From".
   - **2 were the wrong key:**
     - BudgetDetail's archived badge showed the verb "Archive" via `common.archive` → new `common.archived` ("Archived" / "Đã lưu trữ").
     - TransactionDetail's cross-wallet row label reused the lowercase inline badge `home.crossWallet` → new `transactions.crossWalletLabel` ("Cross-wallet" / "Liên ví").
5. **Hardcoded text (6 fixed):**
   - keypad "Backspace" → `common.backspace`, "Confirm" → `common.confirm`;
   - DateField "Clear date" → `common.clearDate`;
   - FAB "Add transaction" → `home.addTransaction`;
   - ThemeToggle switch "Toggle night mode" → `settings.darkMode`;
   - EditTransactionModal `new Error("Transaction unavailable")` → `transactions.unavailable`.

   **Left as is:** the four "Test … toast" buttons in SettingsScreen, which render only under `__DEV__`.
6. **Parity: clean.** en and vi have identical key sets (400 keys after the fixes). 10 identical values, all expected:
   - `auth.emailLabel` "Email";
   - the five theme names (Obsidian, Quartz, Sage, Terracotta, Violet);
   - four language autonyms.
