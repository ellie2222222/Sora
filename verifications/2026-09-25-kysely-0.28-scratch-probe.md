# kysely 0.27.6 → 0.28.17 against a real Postgres and the freshly built API

**Date:** 2026-09-25T02:15:00Z
**Method:** scratch-probe skill
**Verdict:** PASS
**Scope:**
- the dependency bump that fixes all three kysely high advisories, and the CI gate raised from `critical` to `high`;
- every query shape the server uses: auth and refresh rotation, `returningAll` inserts, transactions with the savepointed audit, aggregates, the budget exclusion constraint, paging, and the membership boundary.

The exchange-rate path (`onConflict`) was not exercised, because it makes an external call.

**Files touched:** `server/package.json`, `package-lock.json`, `.github/workflows/ci.yml`
**Related reports:** `2026-09-25-offline-totals-saved-note-encryption.md` (finding 5), `2026-09-24-follow-ups-pass.md`

## Method

- **Install:**
  - `npm install kysely@~0.28.17 -w @sora/server` → the lockfile resolves `node_modules/kysely` 0.28.17, and `server/package.json` has `^0.28.17`.
  - npm also re-sorted `@sora/contracts` alphabetically in `server/package.json`.
- **Checks without a database:**
  - `npm run build -w @sora/contracts` → 0.
  - `npm run typecheck -w @sora/server` → 0.
  - `npm run test -w @sora/server` → 33/33.
- **Audit:**
  - `npm audit --omit=dev` → 0 high, 11 moderate.
  - The moderates are the expo `uuid` chain; npm's only offered fix is `expo@46.0.21` or `expo-splash-screen@55.0.25`, both downgrades.
  - `npm audit --omit=dev --audit-level=high` → exit 0.
- **Scratch database:**
  - Existing containers before the run: `sora-server`, `sora-migrate`, `sora-postgres`, `sora-adminer`, `sora-pgadmin`, `scraper_*`, `vigorous_pare`. All were stopped, and none was touched.
  - Started: `docker run -d --name scratch-kysely-bc53 … -p 127.0.0.1:55433:5432 postgres:17`, database `scratch_kysely_bc53`, then waited with `pg_isready`.
  - `node scripts/migrate.mjs` with `DATABASE_URL` pointing at the scratch database → 001–006 applied.
- **API:** `node dist/src/main.js` with:
  - `PORT=3107`;
  - fake `JWT_SECRET` and `GOOGLE_CLIENT_ID`;
  - `AUTH_RATE_LIMIT_PER_MINUTE=1000`;
  - `EXCHANGE_RATE_API_URL=http://127.0.0.1:9/scratch`, so no external call can succeed.

  `GET /api/v1/health` → `{"status":"ok","database":"up"}`.
- **Probe:** a script in the scratchpad, `kysely-probe.mjs`. Probe users are `probe+{owner,stranger,viewer}-b1d2e103-…@example.invalid`, and entities are named `scratch-b1d2e103-…`.
