3. **Keyboard over sheets on the development build:**
   - Before the fix, the number pad covered the whole verify-email sheet (`kb1`), the same as in Expo Go.
   - **Cause:**
     - `edgeToEdgeEnabled=true` on API 36 stops `adjustResize` from shrinking the window.
     - The sheet's `Modal` draws in a window of its own.
     - `KeyboardAvoidingView` had `behavior={Platform.OS === 'ios' ? 'padding' : undefined}`, so Android did nothing.
   - After `behavior="padding"`, the sheet sits above the keyboard with the field, Confirm and the resend countdown visible (`kb2`).
   - → PASS after the fix
4. **AI chat composer, same cause:** the keyboard hid the composer entirely (`ai1`). After the fix it sits directly above the keyboard (`ai2`), and the layout returns once the keyboard closes (`ai3`). → PASS after the fix
5. **Login:** with the fix, focusing the password field slides the form up, leaving Password and Sign in visible (`lg1`). → PASS
6. **Reopen after expiry (TC-AUTH-38):** sent a code that expired at 11:35, closed the sheet, and reopened it at 11:36:01. The sheet offered "Send code" instead of entry for the dead code (`ex2`). → PASS
